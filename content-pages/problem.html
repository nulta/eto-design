도대체 누가 예제로 테스트를 하는데 제목을 아무 생각도 없이 지을까? 에 관한 문제

2026::deps.problem.server

문제

테스트 케이스 \(T\)가 주어진다. 각 테스트 케이스마다 다음 시행을 수행한다.

길이가 \(n\)인 배열 \(A\)의 인접한 두 요소를 순서대로 XOR 연산하여 새로운 배열 \(B\)를 만든다고 하자. 즉, (\(a_1 \oplus a_2\)), (\(a_3 \oplus a_4\)), \(\dots\), (\(a_{n-1} \oplus a_n\))을 각각 계산하여 배열 \(B\)의 요소로 차례대로 넣는다. 이 때 배열의 길이 \(n = 2^L\)이며, \(\oplus\)는 XOR을 의미한다.

이 과정을 새로운 배열 B에 대해 다시 수행하고, 배열에 단 하나의 요소만 남을 때까지 반복할 때 마지막으로 남은 요소를 반환하라.

입력

첫번째 줄에 T (\(1 \le T \le 100\) )이 주어진다. 각각의 테스트케이스에 대한 입력은 다음과 같다.

첫번째 줄에 문자의 개수 n을 계산하기 위한 L (\(1 \le L \le 60\))이 주어진다.

두번째 줄에 n개의 개수를 가진 배열 A가 공백을 사이에 두고 주어진다.

출력

각 테스트케이스에 대해 문제에서 제시한 마지막 계산 값을 출력한다.

예제

227
